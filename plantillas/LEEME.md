# Plantillas Word del estudio

Deja aquí los archivos `.docx` que usas hoy, primero los modelos vacíos:

- Declaración jurada
- Anexos (al menos uno con tabla, por ejemplo el de acreedores)
- Demanda o solicitud

Con ellos se prepara el mapa **documento → sección → campo variable → fuente del dato → regla de inclusión → validación**,
que es la primera etapa del sistema. Los originales no se modifican: el sistema trabaja sobre copias.

Si más adelante agregas ejemplos completados, que estén anonimizados.
